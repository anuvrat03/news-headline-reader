## 📰 What It Does

This project automatically fetches the top headlines from **10 major newspapers** every day at **6:00 AM IST** and presents them in a clean, elegant web interface.

Headlines are passed through an AI model (via [OpenRouter](https://openrouter.ai/)) to:
- ✂️ Remove clutter and source suffixes
- ✨ Rewrite into crisp, punchy titles
- 📏 Keep each headline under 90 characters
